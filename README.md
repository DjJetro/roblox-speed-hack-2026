## FAQ

**Will the server kick me for high speed?**  
Servers with speed checks kick at ~3–4× default speed. Stay under 3× to avoid kicks in most games.

**Does fly mode work in all games?**  
Fly mode works in most games that don't have fly detection. Games like Jailbreak have anti-fly checks.
